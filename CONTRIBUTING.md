# Contributing to LumaTerm

Thank you for helping improve LumaTerm.

1. Create a branch from `main`.
2. Run `npm ci`, `npm run build`, and `npm test`.
3. Keep changes focused and explain user-visible behavior in the pull request.
4. Do not commit credentials, private keys, generated `release` files, or test data.

Bug reports should include Windows version, LumaTerm version, shell type, and
reproduction steps. Remove hostnames, usernames, paths, and secrets first.
